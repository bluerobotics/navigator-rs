1//! This is a platform-agnostic Rust driver for the ADS1013, ADS1014, ADS1015,
2//! ADS1113, ADS1114, and ADS1115 ultra-small, low-power
3//! analog-to-digital converters (ADC), based on the [`embedded-hal`] traits.
4//!
5//! [`embedded-hal`]: https://github.com/rust-embedded/embedded-hal
6//!
7//! This driver allows you to:
8//! - Set the operating mode to one-shot or continuous. See: [`into_continuous()`].
9//! - Make a measurement in one-shot mode. See: [`read()`][read_os].
10//! - Start continuous conversion mode. See: [`start()`].
11//! - Read the last measurement made in continuous conversion mode. See: [`read()`][read_cont].
12//! - Set the data rate. See: [`set_data_rate()`].
13//! - Set the full-scale range (gain amplifier). See [`set_full_scale_range()`].
14//! - Read whether a measurement is in progress. See: [`is_measurement_in_progress()`].
15//! - Set the ALERT/RDY pin to be used as conversion-ready pin. See: [`use_alert_rdy_pin_as_ready()`].
16//! - Comparator:
17//!     - Set the low and high thresholds. See: [`set_high_threshold_raw()`].
18//!     - Set the comparator mode. See: [`set_comparator_mode()`].
19//!     - Set the comparator polarity. See: [`set_comparator_polarity()`].
20//!     - Set the comparator latching. See: [`set_comparator_latching()`].
21//!     - Set the comparator queue. See: [`set_comparator_queue()`].
22//!     - Disable the comparator. See: [`disable_comparator()`].
23//!

39//! ## The devices
40//!
41//! The devices are precision, low power, 12/16-bit analog-to-digital
42//! converters (ADC) that provide all features necessary to measure the most
43//! common sensor signals in an ultra-small package. Depending on the device,
44//! these  integrate a programmable gain amplifier (PGA), voltage reference,
45//! oscillator and high-accuracy temperature sensor.
46//!
47//! The devices can perform conversions at data rates up to 3300 samples per
48//! second (SPS). The PGA offers input ranges from ±256 mV to ±6.144 V,
49//! allowing both large and small signals to be measured with high resolution.
50//! An input multiplexer (MUX) allows to measure two differential or four
51//! single-ended inputs. The high-accuracy temperature sensor can be used for
52//! system-level temperature monitoring or cold-junction compensation for
53//! thermocouples.
54//!
55//! The devices operate either in continuous-conversion mode, or in a
56//! single-shot mode that automatically powers down after a conversion.
57//! Single-shot mode significantly reduces current consumption during idle
58//! periods. Data is transferred through I2C.
59//!
60//! Here is a comparison of the caracteristics of the devices:
61//!
62//! | Device  | Resolution | Sample Rate  | Channels | Multi-channel | Features        |
63//! |---------|------------|--------------|----------|---------------|-----------------|
64//! | ADS1013 | 12-bit     | Max 3300 SPS | 1        | N/A           |                 |
65//! | ADS1014 | 12-bit     | Max 3300 SPS | 1        | N/A           | Comparator, PGA |
66//! | ADS1015 | 12-bit     | Max 3300 SPS | 4        | Multiplexed   | Comparator, PGA |
67//! | ADS1113 | 16-bit     | Max 860 SPS  | 1        | N/A           |                 |
68//! | ADS1114 | 16-bit     | Max 860 SPS  | 1        | N/A           | Comparator, PGA |
69//! | ADS1115 | 16-bit     | Max 860 SPS  | 4        | Multiplexed   | Comparator, PGA |
70//!
71//! Datasheets:
72//! - [ADS101x](http://www.ti.com/lit/ds/symlink/ads1015.pdf)
73//! - [ADS111x](http://www.ti.com/lit/ds/symlink/ads1115.pdf)
74//!
75//! ## Usage examples (see also examples folder)
76//!
77//! To use this driver, import this crate and an `embedded_hal` implementation,
78//! then instantiate the appropriate device.
79//! In the following examples an instance of the device ADS1013 will be created
80//! as an example. Other devices can be created with similar methods like:
81//! `Ads1x1x::new_ads1114(...)`.
82//!
83//! Please find additional examples using hardware in this repository: [driver-examples]
84//!
85//! [driver-examples]: https://github.com/eldruin/driver-examples
86//!
87//! ### Create a driver instance for the ADS1013
88//!
89//! ```no_run
90//! use linux_embedded_hal::I2cdev;
91//! use ads1x1x::{Ads1x1x, SlaveAddr};
92//!
93//! let dev = I2cdev::new("/dev/i2c-1").unwrap();
94//! let address = SlaveAddr::default();
95//! let adc = Ads1x1x::new_ads1013(dev, address);
96//! // do something...
97//!
98//! // get the I2C device back
99//! let dev = adc.destroy_ads1013();
100//! ```
101//!
102//! ### Create a driver instance for the ADS1013 with an alternative address (method 1)
103//!
104//! ```no_run
105//! use linux_embedded_hal::I2cdev;
106//! use ads1x1x::{Ads1x1x, SlaveAddr};
107//!
108//! let dev = I2cdev::new("/dev/i2c-1").unwrap();
109//! let (bit1, bit0) = (true, false); // last two bits of address
110//! let address = SlaveAddr::Alternative(bit1, bit0);
111//! let adc = Ads1x1x::new_ads1013(dev, address);
112//! ```
113
114//! ### Create a driver instance for the ADS1013 with an alternative address (method 2)
115//!
116//! Using helper `SlaveAddr` creation method depending on the connection of
117//! the `ADDR` pin.
118//!
119//! ```no_run
120//! use linux_embedded_hal::I2cdev;
121//! use ads1x1x::{Ads1x1x, SlaveAddr};
122//!
123//! let dev = I2cdev::new("/dev/i2c-1").unwrap();
124//! // `ADDR` pin connected to SDA results in the 0x4A effective address
125//! let address = SlaveAddr::new_sda();
126//! let adc = Ads1x1x::new_ads1013(dev, address);
127//! ```
128//!
129//! ### Make a one-shot measurement
130//! ```no_run
131//! use ads1x1x::{channel, Ads1x1x, SlaveAddr};
132//! use embedded_hal::adc::OneShot;
133//! use linux_embedded_hal::I2cdev;
134//! use nb::block;
135//!
136//! let dev = I2cdev::new("/dev/i2c-1").unwrap();
137//! let mut adc = Ads1x1x::new_ads1013(dev, SlaveAddr::default());
138//! let measurement = block!(adc.read(&mut channel::DifferentialA0A1)).unwrap();
139//! println!("Measurement: {}", measurement);
140//! let _dev = adc.destroy_ads1013(); // get I2C device back
141//! ```
142//!
143//! ### Change into continuous conversion mode and read the last measurement
144//!
145//! Changing the mode may fail in case there was a communication error.
146//! In this case, you can retrieve the unchanged device from the error type.
147//!
148//! ```no_run
149//! use linux_embedded_hal::I2cdev;
150//! use ads1x1x::{Ads1x1x, ModeChangeError, SlaveAddr};
151//!
152//! let dev = I2cdev::new("/dev/i2c-1").unwrap();
153//! let address = SlaveAddr::default();
154//! let adc = Ads1x1x::new_ads1013(dev, address);
155//! match adc.into_continuous() {
156//!     Err(ModeChangeError::I2C(e, adc)) => /* mode change failed handling */ panic!(),
157//!     Ok(mut adc) => {
158//!         let measurement = adc.read().unwrap();
159//!         // ...
160//!     }
161//! }
162//! ```
163//!
164//!
165//! ### Set the data rate
166//! For 12-bit devices, the available data rates are given by `DataRate12Bit`.
167//! For 16-bit devices, the available data rates are given by `DataRate16Bit`.
168//!
169//! ```no_run
170//! use linux_embedded_hal::I2cdev;
171//! use ads1x1x::{Ads1x1x, DataRate16Bit, SlaveAddr};
172//!
173//! let dev = I2cdev::new("/dev/i2c-1").unwrap();
174//! let address = SlaveAddr::default();
175//! let mut adc = Ads1x1x::new_ads1115(dev, address);
176//! adc.set_data_rate(DataRate16Bit::Sps860).unwrap();
177//! ```
178//!
179//! ### Configure the comparator
180//! Configure the comparator to assert when the voltage drops below -1.5V
181//! or goes above 1.5V in at least two consecutive conversions. Then the
182//! ALERT/RDY pin will be set high and it will be kept so until the
183//! measurement is read or an appropriate SMBus alert response is sent by
184//! the master.
185//!
186//! ```no_run
187//! use linux_embedded_hal::I2cdev;
188//! use ads1x1x::{
189//!     Ads1x1x, SlaveAddr, ComparatorQueue, ComparatorPolarity,
190//!     ComparatorMode, ComparatorLatching, FullScaleRange
191//! };
192//!
193//! let dev = I2cdev::new("/dev/i2c-1").unwrap();
194//! let address = SlaveAddr::default();
195//! let mut adc = Ads1x1x::new_ads1015(dev, address);
196//! adc.set_comparator_queue(ComparatorQueue::Two).unwrap();
197//! adc.set_comparator_polarity(ComparatorPolarity::ActiveHigh).unwrap();
198//! adc.set_comparator_mode(ComparatorMode::Window).unwrap();
199//! adc.set_full_scale_range(FullScaleRange::Within2_048V).unwrap();
200//! adc.set_low_threshold_raw(-1500).unwrap();
201//! adc.set_high_threshold_raw(1500).unwrap();
202//! adc.set_comparator_latching(ComparatorLatching::Latching).unwrap();
203//! ```
